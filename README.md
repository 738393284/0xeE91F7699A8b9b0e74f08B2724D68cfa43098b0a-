# 💳 محفظة دقن زين (Daqn Zain Wallet & Cards System)

نظام مصرفي متكامل وعالي الأمان لإدارة المحافظ الرقمية، البطاقات، وبوابات الدفع، مدعوم بنظام محاسبة دقيق (Ledger) وحماية صارمة ضد تكرار المعاملات.

## 🚀 المميزات الرئيسية
* **محاسبة مزدوجة (Double-Entry Ledger):** فصل تام للأرصدة ومنع أي تلاعب أو تضخم وهمي في الحسابات باستخدام PostgreSQL.
* **حماية تكرار العمليات (Idempotency):** استخدام مفاتيح فريدة لمنع تكرار خصم الأموال أو تنفيذ المدفوعات حتى عند تكرار الطلبات.
* **إدارة البطاقات والمحافظ:** دعم متعدد العملات (YER, USDT, TON) مع التحقق الفوري من صلاحيات البطاقات.
* **أمان متقدم:** استخدام `Helmet`, `Zod`, والتحقق الصارم من بيانات المدخلات.

## 🛠️ التقنيات المستخدمة
* **Backend:** Node.js, Express
* **Database & ORM:** PostgreSQL, Prisma ORM
* **Validation & Security:** Zod, Helmet, CORS
